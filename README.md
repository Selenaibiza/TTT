# 🎮 بازی تیک‌تاک‌تو (PWA)

بازی تیک‌تاک‌تو با HTML/CSS/JavaScript — قابل نصب روی گوشی موبایل و کار کردن به‌صورت آفلاین.

## ✨ امکانات

- 👥 **دو حالت بازی:** دو نفره / مقابل کامپیوتر (Minimax با هرس آلفا-بتا — شکست‌ناپذیر)
- 📱 **قابل نصب روی گوشی (PWA)** — روی اندروید و iOS
- 📶 **آفلاین** — بعد از اولین باز کردن، بدون اینترنت هم کار می‌کند
- 🧮 جدول امتیازها (برد ✕ / مساوی / برد ◯)
- 🎨 طراحی واکنش‌گرا و راست‌چین

## 📂 فایل‌ها

| فایل | توضیح |
|------|-------|
| `index.html` | خود بازی (HTML + CSS + JS در یک فایل) |
| `manifest.webmanifest` | تنظیمات اپ (اسم، آیکون، رنگ) |
| `sw.js` | Service Worker برای حالت آفلاین |
| `icon-192.png` / `icon-512.png` | آیکون‌های اپ |
| `icon-maskable-512.png` | آیکون مخصوص اندروید |
| `apple-touch-icon.png` | آیکون iOS |
| `serve.js` / `start.cmd` | سرور محلی برای تست |
| `gen-icons.ps1` | اسکریپت ساخت آیکون‌ها |
| `tictactoe.apk` | 📦 **نسخهٔ اندروید (نصب مستقیم)** |
| `android/` | سورس و اسکریپت‌های بیلد APK |

## 📦 نسخهٔ اندروید (APK)

فایل `tictactoe.apk` آمادهٔ نصب است — یک اپ کاملاً آفلاین که بازی به‌صورت داخلی در آن قرار دارد.

**نصب روی گوشی:**
1. فایل `tictactoe.apk` را به گوشی منتقل کن (کابل، بلوتوث، تلگرام، …)
2. روی فایل بزن؛ اگر پیام «نصب از منابع ناشناس» آمد، اجازه بده
3. آیکون تیک‌تاک‌تو در صفحهٔ اصلی ظاهر می‌شود

| مشخصه | مقدار |
|-------|-------|
| نام پکیج | `com.tictactoe.game` |
| حداقل اندروید | 5.0 (API 21) |
| هدف | اندروید 14 (API 34) |
| حجم | ~157 KB |
| امضا | v1 + v2 + v3 |
| جهت صفحه | عمودی |

> ⚠️ این یک APK **دیباگ** با کلید تست است و برای نصب شخصی کاملاً مناسب است، اما برای انتشار در Google Play به کلید امضای واقعی نیاز داری.

### ساخت مجدد APK

سورس و اسکریپت‌ها در پوشهٔ `android/` هستند. بیلد بدون Gradle و بدون Android Studio انجام می‌شود (فقط JDK + چند ابزار که خودکار دانلود می‌شوند). اجرا:

```powershell
powershell -ExecutionPolicy Bypass -File android\build.ps1
```


## ▶️ اجرا

**حالت ساده (فقط برای بازی کردن):** فایل `index.html` را دابل‌کلیک کن.

**حالت کامل (برای نصب به‌عنوان اپ):** نصب PWA نیاز به آدرس `http` دارد (فایل `file://` کافی نیست).

```bash
node serve.js
```

یا روی ویندوز فقط `start.cmd` را دابل‌کلیک کن. بعد آدرس `http://localhost:8080` را باز کن.

> جایگزین: افزونهٔ **Live Server** در VS Code.

## 📲 نحوهٔ نصب روی گوشی

**اندروید (Chrome):**
1. آدرس سایت را باز کن
2. بنر سبز «نصب» پایین صفحه را بزن — یا منوی ⋮ و بعد «Add to Home screen»

**iOS (Safari):**
1. آدرس را در **Safari** باز کن (نه Chrome)
2. دکمهٔ اشتراک‌گذاری ⬆️ را بزن
3. «Add to Home Screen» را انتخاب کن

## 🌐 انتشار روی اینترنت (اختیاری)

برای اینکه از هر گوشی‌ای نصبش کنی، پوشه را روی یکی از این‌ها بذار:

- **GitHub Pages** — رایگان و ساده
- **Netlify** / **Vercel** — با کشیدن پوشه (drag & drop) منتشر می‌شود

> نکته: برای کارکرد PWA، آدرس سایت باید **HTTPS** باشد (GitHub Pages و Netlify خودکار HTTPS دارند).
